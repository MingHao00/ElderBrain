# 01 范围说明

对应流程第 1 步「任务边界」。

## 一句话定位

ElderBrain 是一套给 D&D 第五版玩家和 DM 用的规则查询助手：只依据官方 SRD（CC-BY-4.0）作答，每句结论都给出原文出处。项目首先用于练习企业级 RAG 设计，同时开放给公开社区免费试用。

## 使用者与用途

| 项 | 内容 |
| --- | --- |
| 使用者 | D&D 玩家、DM（地下城主） |
| 支持的决定 | 跑团或备团时快速确认一条规则、一个数值，或两版规则的差异 |
| 答错的后果 | 低：浪费时间，用户可以对照原文自行再查 |
| 语言 | 中文、英文，按提问语言作答 |
| 规则版本 | SRD 5.1（2014 规则）与 SRD 5.2.1（2024 规则），默认 5.1 |
| 规模 | 未知，先按小规模设计，用登录、每日配额和全站成本上限兜底 |

## 查询场景

| 场景 | 例子 | 第一期 | 说明 |
| --- | --- | --- | --- |
| 定点查询 | 火球术的射程和伤害 | 是 | 单条目检索 |
| 规则机制解释 | 借机攻击何时触发 | 是 | 单条或少量条目 |
| 版本对比 | 擒抱在两版中的区别 | 是 | 两个版本各检索一次再合并 |
| 条件筛选 | 列出 3 环以下的塑能法术 | 否 | 统计汇总类，走结构化查询，不走检索 |
| 角色创建与升级指引 | 1 级半身人游荡者怎么建卡 | 否 | 跨多章节的流程类问题 |
| 规则交互裁定 | 被擒抱时能否施放有姿势成分的法术 | 否 | 需要多步检索（长路径） |

## 明确不做

- 不回答 SRD 以外的内容，例如非 SRD 的子职业、怪物、模组、世界设定和第三方内容。
- 不替 DM 做最终裁定，只给出规则依据和可能的解读。
- 不用模型自身记忆中的 D&D 知识作答。模型训练数据里有大量非 SRD 内容，混用会让引用失真。
- 不生成自制内容，例如自制怪物、剧情、冒险。
- 不做跑团工具，例如掷骰、角色卡管理、战斗追踪。
- 不回答与 D&D 规则无关的请求，也不回答现实政治问题。

## 负责人

| 角色 | 负责人 | 职责 |
| --- | --- | --- |
| 业务负责人 | 项目作者 | 范围、分期、放行签字 |
| 知识负责人 | 项目作者 | 来源接入、术语表、审核队列 |
| 安全负责人 | 项目作者 | 许可证合规、滥用防护、日志脱敏 |

高影响的失败场景及其负责人：

- 被滥用为免费大模型接口，导致成本失控：安全负责人。
- 引用失真，结论和原文对不上：知识负责人。
- 收到下架请求后没有按时移除：知识负责人。

## 问题类型分布

目前还没有真实用户日志，下面的分布来自 [05-acceptance.md](05-acceptance.md) 的 80 道草稿题。上线后每月用真实问题修正一次，修正后同步调整验收题的比例。

| 类型 | 题数 | 占比 |
| --- | --- | --- |
| 定点查询 | 20 | 25% |
| 规则机制解释 | 16 | 20% |
| 版本对比 | 10 | 12.5% |
| 版本意图与跨版本 | 6 | 7.5% |
| 应拒答或需澄清 | 20 | 25% |
| 后续分期场景（筛选、建卡、交互） | 8 | 10% |

真实问题样本的来源：设计者按上表起草。2026-10-24 项目作者确认 `eval-v0.2` 的问法按原文使用。跑团群和论坛里的真实问法留到上线后补充。
