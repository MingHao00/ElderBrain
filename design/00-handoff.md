## 七、工作约定

- **MinerU：** 程序、虚拟环境、模型与缓存固定在 `E:\MinerU`，不要写入 C 盘。
- **密钥：** API 密钥、OAuth 密钥、JWT 签名密钥、数据库口令只放在环境变量或 `.env` 中，仓库只提交 `.env.example`。
- **改动流程：** 修改分块、嵌入、提示词、模型或过滤策略之前，先跑验收题；改动验收题要升级题目集版本号。
- **原始文件：** 原始文件是事实来源，不在原地修改；更换来源版本时重新登记校验值或提交号。
- **Git 提交信息：** 约定式提交，`<type>(<scope>): <中文描述>`；功能分支用 `feat/<描述>`，修复分支用 `fix/<描述>`。
- **依赖管理：** Python 只用一种包管理器，锁文件提交到版本控制；Docker 基础镜像指定具体版本，容器以非 root 用户运行。
